# 品牌体验基础

“落川流光”是 LC300A 的首版视觉与声音方向。它以层叠山形、向下汇聚的水流和冷静的蓝青色为核心，不复制其他操作系统的商标或视觉资产。

## UI 与 UX

- `branding/product.toml` 是品牌和 light/dark 语义色的唯一配置来源；`branding/experience.toml` 保存排版、间距、圆角、动效和音频默认值。
- light/dark 调色板按语义角色定义，不允许使用颜色作为状态的唯一表达方式。
- 普通文本对比度不得低于 4.5:1，焦点指示不得低于 3:1。
- 指针控件高度至少 36 px，触摸目标至少 44 px。
- Calamares 的按钮、输入框、单选框和复选框落实 44 px 交互目标，键盘焦点使用品牌高对比度描边。
- 动效不超过 280 ms，并尊重系统的减少动态效果设置。
- 字体只声明系统字体族，不在仓库中重新分发未经确认授权的字体文件。

## SFX 与 BGM

- 启动、通知和警告音必须短、无削波、无突变；当前启动音服从系统静音，安静时段策略仍待定义。
- 背景音乐只提供可选预览，默认关闭且禁止自动播放。
- 声音由仓库内脚本确定性生成，不使用来源不明的采样或音乐片段。
- 视觉资产已安装到 Plymouth、Plasma 与 SDDM，事件音已安装为 freedesktop 声音主题；BGM 预览不加入自动启动项。
- 应用菜单通过系统级 XDG 配置收藏 Firefox、Discover、Dolphin 与 Konsole，不保存或复制 Live 用户的 Plasma 运行时状态。
- 系统默认记录当前 Plasma Welcome Center 版本，避免首次会话被上游窗口遮挡；应用仍可手动启动。
