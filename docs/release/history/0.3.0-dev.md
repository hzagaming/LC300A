# 落川OS 300型 0.3.0-dev 公告

发布日期：2026-07-31

`0.3.0-dev` 完成了阶段 3 图形安装器。Live 系统现在可从桌面或应用菜单启动品牌化 Calamares，在图形界面中完成地区、键盘、GPT/UEFI/ext4 分区、用户创建和 GRUB 安装。

本版本重点改进了安装安全与可用性：清空磁盘默认不选中；安装器可完全断网工作；按钮和输入控件达到至少 44 px 的交互高度；SDDM 使用深色品牌壁纸与高对比度前景色。Firefox ESR、Discover、Dolphin 和 Konsole 继续作为默认图形应用提供。

自动验收已验证从 ISO 启动、Live 桌面、浏览器联网、应用商店、有效音频输出、完整离线安装、移除 ISO 后从虚拟硬盘启动、SDDM 登录和 Plasma 桌面。开发镜像信息：

- 文件：`LC300A-x86_64.iso`
- 大小：1,820,854,272 字节
- 软件包：1,617 个
- SHA-256：`00d5d01326a856d0dae417578bb401cce73cbd860b5f367226465e026a1a8b79`

这是开发版本，尚未完成真实硬件、原生 x86_64 发布性能、蓝牙/麦克风和完整中英文本地化验收。安装真实设备前请备份数据并核对目标磁盘。
