# 落川OS 300型 0.3.6-dev 公告

发布日期：2026-08-06

`0.3.6-dev` 是阶段 4 进行中的容量透明度与体验稳定性更新，不代表阶段 4 整体完成。本轮把最低磁盘、推荐磁盘、最低内存和典型安装占用统一纳入产品配置，并在首次欢迎页直观展示。全新构建的 rootfs 实际占用 4,965,994,496 字节（约 4.63 GiB）；产品口径为最低磁盘 16 GiB、推荐 32 GiB、最低内存 2 GiB、典型安装约 6 GiB。

Calamares 欢迎模块现在从同一配置生成 16 GiB 磁盘和 2 GiB 内存门槛。欢迎程序最小窗口调整为 800×600，容量卡片和常用入口在实际 1280×800 framebuffer 中完整显示；离开声音页或手工停止试听会立即停止播放器并释放音源，环境音继续保持不自动启动、不循环、不在后台播放。

深度复查还修正了欢迎程序桌面入口的重复主分类，以及安装器品牌 YAML 中版本字段缩进错误和残留旧版本名称；校验器已收紧版本层级、容量上下界、桌面分类和安装器生成配置的回归断言。Discover 的真实默认仍为 Debian PackageKit，只有检测到已配置的 Flatpak remote 时才追加 Flatpak 后端。

最终镜像通过 59 个单元测试、4 个 os-release fixture、严格 lint/ShellCheck，以及 UEFI 图形启动、纯文字启动、Plasma Wayland 桌面、Konsole、Dolphin、系统设置、欢迎程序四页、Firefox 单标签 HTTPS 正文、Discover 应用卡片、完整断网安装、真实 Calamares 完成页、移除 ISO 后硬盘启动、SDDM 登录、首次欢迎和不重复弹窗验收。自动会话音频捕获 6.87 秒、峰值 7,843、非零采样 150,394，未检测到自动 BGM；手工环境音后总捕获 15.60 秒、非零采样 844,756。开发镜像信息：

- 文件：`LC300A-x86_64.iso`
- 大小：1,808,596,992 字节
- 展开 rootfs：4,965,994,496 字节（约 4.63 GiB）
- 软件包：1,618 个
- SHA-256：`88513683b522bae7d2e13f32fd7c8e30502cd79137c47c99b540f45756b06054`

这是开发版本，尚未完成真实硬件、原生 x86_64 发布性能、蓝牙/麦克风、定制系统设置/更新程序/系统报告和完整中英文本地化验收。安装真实设备前请备份数据并核对目标磁盘。

旧版本公告位于 `docs/release/history/`。
