# 落川OS 300型 0.2.0 公告

发布日期：2026-07-29

`0.2.0` 完成了阶段 2 图形桌面：Live ISO 可从 GRUB 选择图形或纯文字模式，图形模式会自动进入 Plasma Wayland，并提供 Firefox ESR、Discover、Dolphin 和 Konsole。

本版本接入“落川流光”品牌壁纸、Logo、Plymouth 启动画面和默认静音策略下的可选声音体验；QEMU/OVMF 已验证真实帧缓冲、浏览器联网、应用窗口和非静音音频输出。

阶段 2 开发镜像为 1,788,637,184 字节、1,581 个包，SHA-256：`b1e3aac4dcd74fdcec00e25d74260fa273551f9b756f68519c59e6585fd01501`。

该版本尚不包含经过验收的图形安装器；当前公告请查看项目根目录 `ANNOUNCEMENT.md`。
