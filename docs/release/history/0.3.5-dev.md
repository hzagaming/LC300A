# 落川OS 300型 0.3.5-dev 公告

发布日期：2026-08-05

`0.3.5-dev` 完成阶段 4 桌面体验的第一个增量，但不代表阶段 4 整体完成。本轮加入 Qt 6/QML 四步首次登录欢迎程序，并重新构建、启动和安装成品 ISO，逐页复核 Live 桌面、欢迎程序、系统应用、安装器、SDDM、安装后桌面、SFX 与 BGM。

欢迎程序只在安装后首次登录自动显示，Live 环境不弹出；用户可浏览系统入口、隐私默认值和声音策略，打开系统设置、Discover 与支持页，并手工试听启动音或环境音。所有声音默认不自动播放、不循环。完成状态写入用户私有配置并固定为 `0600`，后续登录不重复弹出；URI 动作 helper 只接受严格白名单，不使用提权或 shell 拼接。

首次登录启动器会等待 PlasmaShell 的 D-Bus Ping 成功并留出绘制时间，解决欢迎窗口先于壁纸和面板出现时的黑底体验。安装器 E2E 也修复了把 97% 进度页误报为完成页的假阳性：现在必须等待真正 Finish 页连续稳定绘制后，才会移除 ISO 并启动安装后的系统。

最终镜像通过 55 个单元测试、4 个 os-release fixture、严格 lint/ShellCheck，以及 UEFI 图形启动、纯文字启动、Plasma 桌面、Konsole、Dolphin、系统设置、欢迎程序四页、Firefox 单标签 HTTPS 正文、Discover 应用卡片、完整断网安装、真实 Calamares 完成页、移除 ISO 后硬盘启动、SDDM 登录、首次欢迎和不重复弹窗验收。自动会话音频捕获 6.92 秒、峰值 7,843、非零采样 150,394，未检测到自动 BGM；手工环境音后总捕获 15.62 秒、非零采样 844,756。开发镜像信息：

- 文件：`LC300A-x86_64.iso`
- 大小：1,808,592,896 字节
- 软件包：1,618 个
- SHA-256：`7280d965872bca867e9f7cac30d7a7094c3aaf2f7c06a515f11f30ef8f3f698a`

这是开发版本，尚未完成真实硬件、原生 x86_64 发布性能、蓝牙/麦克风和完整中英文本地化验收。安装真实设备前请备份数据并核对目标磁盘。

旧版本公告位于 `docs/release/history/`。
